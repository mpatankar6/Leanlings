# Where to learn more

Leanlings is a crash course. When you're ready for more, these are good next
steps. Resources marked **Mathlib** use Lean's large mathematics library,
which Leanlings deliberately avoids. They're excellent, but expect tactics
(like `ring` or `linarith`) that you haven't seen here.

## Books

- **[Theorem Proving in Lean 4](https://lean-lang.org/theorem_proving_in_lean4/)**:
  the standard introduction to Lean's logic, from dependent type theory to
  tactics and inductive types. The natural next step after Leanlings.
- **[Functional Programming in Lean](https://lean-lang.org/functional_programming_in_lean/)**:
  Lean as a programming language. Good if you want to write programs and
  prove things about them.
- **[Mathematics in Lean](https://leanprover-community.github.io/mathematics_in_lean/)**
  (**Mathlib**): formalizing undergraduate mathematics.
- **[The Mechanics of Proof](https://hrmacbeth.github.io/math2001/)** by
  Heather Macbeth (**Mathlib**): an introduction to writing proofs, taught
  with Lean.

## Games

- **[Natural Number Game](https://adam.math.hhu.de/#/g/leanprover-community/NNG4)**:
  build the natural numbers from scratch and prove their basic properties,
  level by level, in the browser. A great companion to Chapter 8.
- **[Lean Game Server](https://adam.math.hhu.de/)**: the Natural Number Game
  and other games in the same style.

## Reference

- **[Lean Language Reference](https://lean-lang.org/doc/reference/latest/)**:
  the official, detailed description of the language and its tactics. A
  reference rather than a tutorial.
- **[Learn page on lean-lang.org](https://lean-lang.org/learn/)**: links to the
  official books, games and tools.

## Community

- **[Lean Zulip chat](https://leanprover.zulipchat.com/)**: the main chat for
  the Lean community.
